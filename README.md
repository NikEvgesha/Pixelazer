# Pixelazer

Desktop-утилита на JavaFX для преобразования PNG/JPEG в пиксель-арт. При уменьшении
разрешения контуры получают больший вес, поэтому тонкие линии и силуэты сохраняются
лучше, чем при обычном усреднении.

## Запуск

Требуется JDK 17+.

```powershell
gradle run
```

## Проверка

```powershell
gradle test
```

## Переносимая Windows-версия

```powershell
.\gradlew.bat clean test packagePortable
```

Команда создаёт `build/package/Pixelazer/Pixelazer.exe` и архив
`build/distributions/Pixelazer-portable.zip`. В комплект включён собственный Java runtime,
поэтому установленная Java для запуска не требуется.

Экспорт PNG использует строгий индексированный формат (`color type 3`). Таблица `PLTE`
содержит только реально используемые цвета, а прозрачность записывается через `tRNS`.

Алгоритм работает в два этапа: edge-aware downsampling, затем сокращение палитры
методом weighted median cut (от 2 до 32 цветов) с подбором ближайшего цвета в Lab.

После преобразования кнопка «Редактировать результат» открывает пиксельный редактор.
В нём можно выбрать цвет итоговой палитры, рисовать кликом или перетаскиванием мыши
и менять целочисленный масштаб без размытия пикселей. Правки попадают в экспортируемый
PNG только после нажатия «Применить».

Режим «Лайн-арт / комикс» поддерживает дополнительные настройки: уровень детализации,
автоматический или ручной выбор цвета контура, толщину линии и замыкание небольших
разрывов. Режим «Иллюстрация» использует стабильные внутренние параметры и не зависит
от настроек контуров.

Для фотографий доступны Floyd–Steinberg, упорядоченный и ограниченный контурами
дизеринг. Любой режим поддерживает обязательные цвета палитры. Кнопка «Сравнить режимы»
строит варианты «Фото», «Иллюстрация» и «Лайн-арт» рядом и позволяет выбрать один из них.
Панель автоматически скрывает параметры, не относящиеся к выбранному режиму.
Обязательный цвет можно задать стандартным выбором цвета или взять пипеткой непосредственно
с исходного изображения в отдельном пиксельном окне без сглаживания.

Блок «Пиксельная сетка» позволяет автоматически подобрать фазу сетки по контрастным
деталям, отключить смещение либо задать смещение X/Y вручную. После преобразования
кнопка «Редактировать палитру» позволяет заменить любой итоговый цвет и сразу
переназначает все соответствующие пиксели результата.
